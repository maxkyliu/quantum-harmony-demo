How it works

  1. Plan. YuE2 writes the song as an editable lead sheet: a melody line plus one chord symbol per bar.
  2. Blur. The chords become a block-chord MIDI track. Moth Quantum's blur-midi-v1 engine encodes the piano roll into qubits and rotates them, so each chord's notes bleed into neighbouring pitches and beats.
  3. Read back. For every original chord span, the blurred notes are matched to the closest chord YuE2 understands, kept within the song's key; the original chord stays unless another fits clearly better.
  4. Render. Only the chord symbols change in the score (the melody is verified byte-for-byte), and YuE2 renders the new score with the original lyrics and seed.

At strength 0.3 the blur mostly recolours chords (C → Csus4, F → Fmaj7). At 0.5 it also swaps in related chords (Am → Fmaj7, G → Em). The code is the yue2_harmony.py tool in moth-quantum-skills.
